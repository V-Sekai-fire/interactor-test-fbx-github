# interactor-test-fbx-github

A model-import test fixture: a telescope model from a public rendering sample set, stored as a reference OBJ with its materials.

## What it is for

The reference OBJ carries ufbx matching hints, and the JSON file beside it records the model's title, author, source and licence.
